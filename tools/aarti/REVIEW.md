# Aarti content review — 2026-10-05

Initial review: reviewed all 84 supplied entries. Retained 80, removed 4, added 5; count 85. The subsequent requested expansion adds 20 more, bringing the current total to **105**, version **1.5**.

IDs of retained entries and the API field names are preserved. Removed IDs are retired; additions use IDs 92–96.

The `english` field remains Roman lyrics, now consistent IAST transliteration of the Devanagari field. Hindi/Awadhi spelling is transliterated literally; this is not an English translation or a phonetic schwa-deletion guide.

Sources were compared for the traditional texts, not their modern translations or explanatory articles. Regional readings exist; this collection uses one commonly recited rendition rather than claiming a universal critical edition.

Raghupati Raghava (40) now uses the Ram-bhakti rendition beginning “सुन्दर विग्रह मेघश्याम”, replacing the Gandhi-associated verses in both scripts. Its earliest authorship is not asserted.

Long works now include the missing verses: Ram Raksha (38 numbered stanzas plus invocation/dhyana), Mahishasura Mardini (21), Achyutashtakam (8 plus phalashruti), Bhavani/Yamuna/Narmada Ashtakam (8 plus concluding verses), Gita Dhyanam (9), and Shri Hari Stotram (8 plus phalashruti). Vishnu Sahasranamam includes all 107 name-stanzas plus the traditional concluding stanza and phalashruti; numbering restarts in the conclusion.

Short named prayers (5, 7, 8, 10, 41, 64, 88, 91) no longer contain unrelated prayers or invented padding. Guru Vandana and Narayani Stuti intentionally remain named prayer collections. Thumak Chalat retains the supplied commonly sung four-stanza performance version.

Audio URLs are empty; existing durations are unverified performance estimates. New items have an empty duration rather than an invented recording length. Existing images are preserved and reused by deity; image identity/licensing and playback were outside this lyrics review.
